# Pocket Wilds, Simplified Chinese: forbidden words (owner rule of 2026-10-06, Docs/Design/Vocabulary_Rule.md).
# Nothing religious or divine in any text. This file and the rule document are the only places these words may appear.
# Format: one word or stem per line; the comment line above each entry gives its meaning.
# Chinese has no spaces between words: every entry is matched anywhere in a text (substring).
# Kept allowed on purpose: 星座 (constellations), 星光 (starlight), 睡莲 (water lily), 灯笼 (everyday lantern),
# 水仙 and 仙人掌 (plants), 拜托 (please), 灵活 (nimble).
# Replacements: refuge = 家园, top rarity = 梦幻, glow = 之光 / 光点, rendez-vous = 每日相聚.
