#   CHAR  REGIONS  STROKES  IDS
# REGIONS: J = Japanese (shinjitai), S = Simplified Chinese, T = Traditional Chinese (Taiwan).
# STROKES: strokes as we draw them (one number, or per region: J7,S7,T8). The verification compares it with the
#   strokes the engine actually draws for that region. Same shape, other counting habit: 阝 and 廴 are drawn in two
#   strokes, 钅 in four, 佥 in six, 臣 in six,
#   以 in four, the Taiwan 艹 in four; those characters carry the drawn count.
# IDS: Ideographic Description Sequence over our components ('*' = the component of the same name). A code point
#   whose glyph differs between regions has one line per form; components may also differ per region (@J @S @T in
#   the components file), e.g. 艹 has four strokes in Taiwan, 户 starts with a bar, a dot or a slash.
# Composite components (NAME = IDS) may live here too. Nothing religious in this set (Docs/Design/Vocabulary_Rule.md).
